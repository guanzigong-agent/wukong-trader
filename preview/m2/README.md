## M2-R2 到站即显示本站商品与价格（2026-10-29）

用户要求进入站点就显示本站商品列表及价格。开局所在站、点击地图到站、升级后新图首站均自动打开行情面板；返回地图后，也可从本站入口再次查看。

- 六张图共36站，每站列出甘草、镔铁砂、蚕丝、松醪，以及对应买入价、卖出价、演示余量。
- 买入价指玩家买货的价格，卖出价指玩家卖货的价格。各站报价不同，同站回访保持固定，方便比价。
- 手机为底部行情面板，电脑为地图上的浮层，关闭后仍在原站点及同张地图。
- 新增`market-data.js`保存本作演示商品与站点报价；`market-preview.js`只负责到站行情展示。
- 当前仅查看固定演示行情，未新增商品买卖与持仓结算。原地图收益按钮改为“演示本程收益”，与实际商品交易区分。

## M2-R3 可操作买入卖出（2026-10-29）

用户指出价格表无法操作。本版每件商品已增加数量输入、加减、最多买、全部持有、买入及卖出按钮；进入站点后即可交易。

- 沿用原M1开局：1200文、20格行囊。买入扣钱并入囊；卖出回款并减持。
- 卖出按先买先卖结转购入成本，累计净收益包含实际盈利及亏损；买入本身不计利润。持有数量、平均成本、当前现金和预计盈亏实时更新。
- 钱不足、行囊满、货物不足和非法数量会给出反馈，拒绝结算；失败不改变钱货。
- 本版不设商人供货限额，以玩家资金和20格容量限制可买数量。此前的演示余量已移除，改为玩家持有数量。
- 收益达标自动换整图，钱货随行。已开启的地图不因之后亏损倒退。原有模拟加钱按钮及URL伪造收益入口已移除。
- 价格与中间门槛仍为试玩配置；不含动态行情、角色能力及持久存档。状态保存在内存，刷新重置。
- 示例：到溪畔药铺，以26文买入10件甘草；返回地图，前往山口关隘，以40文卖出，共赚140文。

## M2-R4 移动刷新行情（2026-10-30）

用户要求物价随移动变化，参照《最强nba人贩子》。本轮只参考该项目`src/prototype/rules.mjs`的移动/行情机制，不修改篮球游戏。

- 前往不同站点：行程加1，四种商品推进一轮行情。返回之前到过的站点，也使用新一轮报价。
- 同轮买卖、关开面板、改数量、换外观、重复点击当前站都不刷价。升级进入新地图也属于移动，只推进1轮。
- 报价显示行情轮次和涨跌，涨跌比较该站在上一轮的价格，非与上一站比较。地图仍只有当前到站的报价可操作。
- 波动参数为本轮试玩提案：72%普通波动5%～15%，23%较大波动15%～25%，5%大幅波动25%～40%；行情因子在0.3～2.5之间，叠加各站基础报价差。极端高低价会有回归倾向。
- 行情按行程序列确定，可重放；读取/刷新面板不会抽取新随机结果。刷新整个页面仍重新开局，尚未增加存档。
- 实际买卖、可买数量及预计盈亏使用当轮报价。持仓成本不因移动重估，卖出仍按先买先卖结转成本，亏损也计入净收益。
- 1200文开局、20格行囊、每图六点、十万文花果山条件保留；不引入NBA游戏的30天限制或排行榜系统。此前固定26文买入/40文卖出的路线不再保证固定价差。
